# 東方戮影塔 〜 Formless Barrage

> 一款东方 Project 风格的弹幕 STG + 卡牌构筑游戏。你的火力不取决于自机，而取决于你手里握着哪些符片。
>
> **本作品是东方 Project 的二次创作。** 非官方作品，与上海爱丽丝幻乐团无从属关系。

**仓库名：** `SlayingShadowTower` · **版本：** v0.1.0（开发中）

> **名字释义：** 戮（杀伐）、影（蜃景）、塔（舞台）——三个独立意象并列，同东方正作的命名方式（如星蓮船＝星・蓮・船）。
