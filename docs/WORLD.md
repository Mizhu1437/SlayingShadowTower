## 〇、一句话概括

> 妖怪之山附近出现了一座高塔的蜃景。八云紫管不了它——蜃没有境界。自机进塔，发现是渡里贝子：她从外界信息的洪流里诞生，想让幻想乡承认她的蜃景才是真实。她仿造天弓千亦的卡牌，把外界信息封成符片；那些符片力量暴走，成了塔里的怪物。最终她被打醒，蜃景散去，而幻想乡依然愿意听她讲那些「真相」。

## 二、渡里贝子：官方设定

> 以下为原作设定，可直接引用，非原创。

| 项 | 官方设定 |
| :--- | :--- |
| 种族 | **蜃** |
| 能力 | **显现海市蜃楼程度的能力** |
| 出身 | **信息之海** |
| 职业 | 信息汲取者 |
| 初登场 | 《东方锦上京》EX 面 BOSS |
| 别名 | 渡里妮娜 / Watari Nina |

**原作文本（关键三句）：**

> 「从外界涌入的所有信息都带着新鲜感。」
> 「她是在信息之海中诞生的新型贝类妖怪。她吸收了过多的信息，却无暇分辨其真伪。」
> 「涌入的信息尽是些标榜『隐藏真相』的内容。」

**她的战斗动机，官方原文就有：**

> 「苏醒者必须战斗。唯有战斗，才能夺回自己！」

**来源：** [中文东方维基](https://zh.touhouwiki.net/index.php?title=%E6%B8%A1%E9%87%8C%E8%B4%9D%E5%AD%90) · [萌娘百科](https://zh.moegirl.org.cn/zh-hans/%E6%B8%A1%E9%87%8C%E8%B4%9D%E5%AD%90)

### 2.1 本作的定位

| 项 | 本作设定 |
| :--- | :--- |
| **她造了什么** | 妖怪之山附近的高塔蜃景，及塔内的一切 |
| **她为什么造** | 她相信**蜃景才是真实**，想让幻想乡承认这一点 |
| **她为什么和你打** | 你要打散蜃景，等于否定她存在的唯一证明 |
| **她的手段** | 仿造千亦的卡牌，把外界信息封进符片 |
| **失控的原因** | 信息太多，她无暇分辨真伪，符片力量暴走 |

### 2.2 战斗动机（核心矛盾）

> **她不是在作恶。她在证明自己是真的。**

她是从「信息之海」诞生的妖怪。她的全部存在就是「显现」。而显现的东西会被说成假的——**所以「幻」这个字对她来说是一种否定。**

她把蜃景搭成一座塔，把信息封成卡，把卡造成怪物。这一切都是为了让幻想乡看见：**我造的东西是能站住的。**

**这让她成为本作唯一有情感重量的角色。** 她比任何「想毁灭世界的 BOSS」都更难对付，因为你要打的不是一个坏人，是一个**在自证存在的人**。

### 2.3 一个她没意识到的悖论（全作的题眼）

> **幻想乡本来就是幻想栖身的地方。**
>
> 妖怪、幽灵、神明、海市蜃楼——这些东西在幻想乡不需要「被承认为真实」。**它们的存在方式就是幻想，而这本身就是被接受的。**
>
> 她拼命要争的那个许可，幻想乡从第一天起就给了所有东西。
>
> **她不知道。因为她是从「信息之海」里醒来的，而信息之海里只有「真 / 假」两个选项。**

**这个设计的意义：** 她的失败不是「坏事没做成」，而是「她一直在打一场不必要的仗」。这比单纯的战斗胜利有回味。

## 三、核心设定：灵力无型，信息给型

### 3.1 设定原文

> **自机的灵力本身是"无型"的。**
> 徒手打出的弹幕只是灵力的散散喷发——能伤人，但浪费、稀疏、缓慢。
>
> **符片是"凝固的术式"，本质是"被封存的信息"。**
> 信息本身有结构。那个结构就是**型**。灵力注进这个型，就被塑造成有杀伤力的弹幕。

### 3.2 钱与卡是同一物质的两个形态（本版新增，核心）

这是全作最漂亮的一处自洽：

| 形态 | 是什么 | 表现 |
| :--- | :--- | :--- |
| **无型的信息** | 散的蜃，未成形 | **钱（蜃銭）** |
| **有型的信息** | 已凝固成一个「型」 | **符片（卡牌）** |

于是三句话说的是同一件事：

```
自机的灵力       无型  →  需要符片给它一个型
蜃的信息         无型  →  需要符片把它压成一个型
钱               无型  →  花掉它就能换到一个已成型的符片
```

> **钱是未成型的信息，卡是已成型的信息。花钱买卡，就是"给无形之物定型"。**

### 3.3 它一次性解释了全部机制

| 设计问题 | 答案 |
| :--- | :--- |
| **为什么被动卡能完全决定攻击形态** | 符片就是"型"本身，不是加成，是形状 |
| **为什么零卡开局能打但很难** | 裸弹能伤敌，只是效率极低 |
| **为什么主动卡消耗能量** | 主动卡是"完整展开"符片内的结构，展开需要灌满灵力 |
| **为什么手牌只有 5 格** | 同时维持多个"型"是自机的精神/灵力分配上限 |
| **为什么定时抽牌** | 唤出一张符片需要集中精神；弹幕缠身时只能间歇性地做 |
| **为什么弃掉最前面那张** | 维持旧"型"要持续分心；新符片加入，最旧的率先失稳散逸 |
| **为什么牌堆空了能洗回** | 散逸不是消失，是回落到游离态；游离的术式会再次凝聚 |
| **为什么打怪掉卡** | **怪物本来就是一张"型"暴走的符片**，击破 = 把它压回型里 |
| **为什么打怪掉钱** | 击破时散出的未成型残渣 |
| **为什么能在塔内交易** | 同一物质的不同形态互换，本来就不需要理由 |
| **为什么灵力能烧符片** | 两者是同一类东西 |

### 3.4 视觉要求（低成本高收益）

**既然怪物就是卡牌的投影，就让它长得像卡。**

| 要求 | 说明 |
| :--- | :--- |
| 部分敌人用**符札轮廓** | 悬浮的巨大纸片、边缘烧焦的札、卷曲的符 |
| 击破时**化为一张卡消散** | 视觉上自证"它本来就是卡" |
| 成本 | 几何图形 + 一个卡牌轮廓，几乎为零 |

**这可能是整个游戏最便宜的识别点。** 玩家玩三分钟就能说出「这游戏的怪是卡变的」。

## 四、天弓千亦：真身 + 伪身（双层设计）

### 4.1 官方依据

天弓千亦是《东方虹龙洞》的最终 BOSS，权能为**主张"无主物"的所有权**。正作中，虹龙洞的能力卡本身就是被她散播出去的无主物。

### 4.2 本作的双层安排

| 位置 | 是谁 | 做什么 |
| :--- | :--- | :--- |
| **塔外** | **真千亦** | 登场，说明塔里的卡是怎么回事，然后进塔 |
| **塔内（商店）** | **伪千亦** | 是贝子造的卡牌投影，因模仿了千亦的能力而能交易 |

### 4.3 为什么这个设计好

| 收益 | 说明 |
| :--- | :--- |
| **补上中 BOSS** | 玩家打碎伪千亦，构成一场硬仗（1 张符卡） |
| **真千亦不需要打** | 她的登场是解说，不是战斗 |
| **贝子为什么仿造她** | 她需要"商人"这个角色，让卡"看起来合法" |
| **最好的喜剧时机** | 玩家刚把一个"千亦"打碎，真千亦在旁边看着 |
| **主题呼应** | 千亦是"所有权"的神，而所有权的前提是**分辨真假** |

### 4.4 战斗规格（伪千亦）

| 项 | 规格 |
| :--- | :--- |
| 定位 | 中 BOSS，非正式死斗（玩家以为在打商人） |
| 符卡 | **1 张** |
| 血量 | 约为贝子的 1/3 |
| 弹幕 | **复用已有 pattern 组合，不新增弹幕类型** |
| 特殊 | 战后掉一张裂开的卡（伏笔） |

### 4.5 千亦的经济职能

| 职能 | 说明 |
| :--- | :--- |
| 主张无主物所有权 | 贝子造的卡原本无主，千亦可主张 |
| 货币互通 | 让蜃銭与幻想乡货币兼容 |
| 开店 | 塔内固定"市"节点，走进去开商店 |

## 五、八云紫：她不是不管，是这个她管不了

### 5.1 设定

> **蜃景没有"境界"可言。**
> 八云紫的权能是操纵境界，而境界存在于**有边界的东西**之间。一座海市蜃楼没有边界、没有表里、没有内外——**她的能力对它无效。**
>
> 但她能做另一件事：**守住蜃景扩散的外缘**，不让它吞掉整个妖怪之山。
>
> 自机能进塔，正因为紫在外面把边界钉死了。

### 5.2 三重收益

| 收益 | 说明 |
| :--- | :--- |
| 缺席有真实理由 | 不是剧情漏洞，是能力限制 |
| 她有英雄行为 | 在外面死守，不是袖手旁观 |
| 解释影响范围 | 塔被限制在妖怪之山，其他地方没事 |

### 5.3 她的台词

> 「那东西没有境界，我碰不到它。但我能挡住它蔓延——里面就交给你们了。」

## 七、塔的结构：三幕 = 信息之海的三层

> **2026-10-26 调整：** 塔的层次与游戏的**三幕结构**对齐。三幕正好对应三层信息。

| 幕 | 场景 | 层 | 内容 | 玩法特征 | 关底 BOSS |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **第一幕** | **塔外** | **流言** | 传闻、口耳相传的碎语、妖怪之山的八卦 | 弱怪，密集但脆 | **真千亦** |
| **第二幕** | 塔内 | **影像** | 图像、画面、外界的视觉信息 | 弹幕视觉化，多种图案 | 占位待定 |
| **第三幕** | 塔内 | **伪真** | 标榜「隐藏真相」的信息 | **弹幕会伪装、误导** | **渡里贝子** |

### 7.1 为什么这个对齐是对的

| 理由 | 说明 |
| :--- | :--- |
| **难度曲线天然递增** | 流言 → 影像 → 伪真，一层比一层难辨 |
| **「伪真」放最后一幕** | 玩家的基本技能已练熟，这时才考"分辨真假" |
| **第一幕在塔外** | 天然是"还没进塔、最浅的一层"，与流言对应 |

### 7.2 「伪真」层特别说明

这一层直接对应贝子官方设定的核心：

> 「她吸收了过多的信息，却无暇分辨其真伪」
> 「尽是些标榜『隐藏真相』的内容」

**设计：弹幕会骗人。** 例如：
- 看起来是子弹，其实是背景
- 看起来是背景，其实是子弹
- 假装分裂，实际不分
- 假装不分，实际分裂

**这是机制与设定的完美结合，也是别处见不到的设计。**

### 7.3 第一幕关底：真千亦为什么开打

> **她兼容了塔内的经济系统，这会被自机误认为她就是黑幕。**

| 自机的推理 | 千亦的立场 |
| :--- | :--- |
| 塔里出现人 | 我只是在主张所有权而已 |
| 还有人在做生意 | 无主物总得有个主人 |
| 而且钱能流通 | 我认了它，它就能用 |
| **→ 她就是源头** | **→ 我什么都没做** |

**双方都有正当理由，而且理由是同一件事的两面。** 这是标准的东方式误会，不需要额外解释。

战后她解释清楚，并开放交易——**她被打不是因为错了，是因为她说得太像在黑市经营。**

### 7.4 对 MVP 的意义

三幕全部实现。但代码里把幕编号当参数写，将来加第四幕只是加 JSON。

## 八、货币：蜃銭

| 项 | 内容 |
| :--- | :--- |
| **名称** | 蜃銭（しんせん）— 占位可用 `coin` |
| **本质** | 蜃景凝结的**未成型信息残渣** |
| **掉落** | 击破塔内怪物（= 暴走的符片）时散出 |
| **为何有实体** | 千亦主张了它们的所有权，于是它们成了真的货币 |
| **为何不随蜃景消散** | 千亦提前把"所有权"固定下来了 |

### 8.1 经济闭环

```
打怪（暴走的符片）→ 掉蜃銭（未成型残渣）→ 千亦收下 → 买符片（成型的卡）→ 打更强的怪
```

**这条链在世界观内完全自洽：钱和卡本来就是同一种东西的两个状态，交易只是形态转换。**

### 8.2 三样东西、三个来源、一套规则

| 物 | 形态 | 来源 | 为何可交易 |
| :--- | :--- | :--- | :--- |
| 蜃銭 | 无型的信息 | 蜃景凝结 | 千亦主张所有权 |
| 符片 | 有型的信息 | 外界信息被封存 | 千亦主张所有权 |
| 灵力 | 自机自身，无型 | 自机 | 不可交易，需符片定型 |

## 九、结局

### 9.1 用户的设定

> 幻想乡要稳定，可能不能允许外界信息大量涌入。贝子暴走的能力被压制后，不再做这么危险的行为了。
> **但她还是可以像以前一样，向幻想乡展示她认为的「真相」。**

### 9.2 这个处理好在哪

| 常见写法 | 你的写法 |
| :--- | :--- |
| 她认错，从此不再显现蜃景 | **她不再做危险的事，但继续展示她想展示的东西** |
| 幻想乡驱逐她 | 幻想乡**允许她存在**，只是限制了规模 |
| 她的欲望被否定 | 她的欲望被**保留**，只是被约束 |

**这是最像幻想乡的结局。** 幻想乡从不消灭异端，它只让异端学会共处。

### 9.3 收场流程

```
自机击败贝子
    ↓
蜃景开始消散。她终于看清楚了。
    ↓
贝子：「……原来这里，本来就没有塔。」
    ↓
自机：「塔是真的。只是它是蜃而已。」
    ↓
她不再维持整座塔，但留下了几张卡。
    ↓
千亦把遗留的符片与蜃銭纳入幻想乡的货币体系
    ↓
紫撤去外围的封锁
```

### 9.4 结局台词草稿

```
贝子：这里……没有塔。
贝子：你们说没有。可是刚才明明有。
灵梦（占位）：有啊。刚才还在打呢。

贝子：那它是假的。
     ：假的东西，不算存在吧。

紫（占位）：幻不是假的。
          ：在幻想乡，幻就是幻，不用装成别的东西。
          ：你也不用。

贝子：（沉默）
     ：……那我可以留在这里吗？
紫（占位）：留在妖怪之山，可以。
          ：但不要再把整座山盖起来了。
贝子：好。
     ：那我至少可以把看到的东西讲给你们听吧。
```

**最后一句是全作的落点：** 她想让人看到"真相"的欲望没有被否定，只是换了规模。

## 十、BOSS 对话脚本

### 10.1 塔外 · 真千亦登场

```
千亦：哎呀，客人。你们也是为那座塔来的？
千亦：里面的东西在流通，而且流的是我的东西。
灵梦（占位）：妳做的？
千亦：我做过的东西，被人照着做了一个。
     ：在这种情况下，那个仿的办法，也是无主物哦。
灵梦（占位）：……所以算是谁做的？
千亦：这就是我接下来要去看的事。
     ：先进去吧。里面应该有个市。
```

**设计意图：** 她说的每句话都是她权能的直接应用。**"仿的办法也是无主物"这句非常千亦**——她能把任何东西都拆解成所有权问题。

### 10.2 塔内 · 伪千亦（中 BOSS 战前）

```
伪千亦：欢迎光临。
灵梦（占位）：……千亦？
伪千亦：这边的卡，价格公道。
灵梦（占位）：刚才那个还说先进来看看……
       ：妳怎么也进来了？
伪千亦：（微笑）……
灵梦（占位）：……我不问了。先打。
```

**设计意图：** 自机先"震惊"，然后放弃理解——**这是东方自机一贯的处理方式**，也符合玩家的心理（"算了，先打了再说"）。

### 10.3 伪千亦 · 战败（识破）

```
（碎裂。散成一张裂开的卡）
灵梦（占位）：……果然。
       ：这玩意儿，跟刚才那些东西一个味儿。
       ：是卡变的。
```

**关键：** 玩家在打碎它的瞬间就明白「塔里的东西都是卡」。**这个信息不是台词的功劳，是战斗本身给出的。**

### 10.4 真千亦 · 现身（商店开启）

```
千亦：打得挺起劲嘛。
灵梦（占位）：妳到底是哪个？
千亦：我在这儿。
     ：刚才那个，是有人仿着我做的。
     ：仿得还挺像的——连买卖的规矩都学去了。
灵梦（占位）：所以现在能买东西了？
千亦：能。钱我也认。
     ：本来只是些散的蜃，没什么价值。
     ：但我认了它，它就有了主。
     ：有主的东西，就能交易。
```

**设计意图：** 她不需要道歉、不需要解释太多。**"我认了它，它就有了主"** —— 一句话说完她的全部权能。

### 10.5 贝子 · 战前

```
贝子：又来人了。
     ：你们也是来说这里是假的吗？

贝子：我看见了。外界的一切，全在这里。
     ：什么都在，什么都是真的。
     ：为什么你们说它是假的？

灵梦（占位）：因为这里本来没有塔。
贝子：那现在有了！
     ：是我让它有的。
     ：这就够了，对不对？
```

**设计意图：** 她的每一句话都在自证，而自证这件事本身就是她的痛点。**「这就够了，对不对？」是全场最脆弱的一句**——她在向敌人求一个承认。

```
【第一关 · 第 1 层「流言」】
    ↓

    ↓

    ↓
结局
```

### 11.1 为什么商店在这个位置

> **商店必须出现在"你还需要用卡"的地方之前。**

若商店在关底之后，玩家买了卡却无处可用，等于没有被验证。当前顺序让玩家买到新符片后立即投入最后的战斗——**这才是真正的肉鸽循环**。

### 12.5 致敬声明（已决定写）

```
本作的卡牌构筑系统、能量机制、主动/被动卡分类与商店设计，
借鉴并致敬《杀戮尖塔》（Slay the Spire, Mega Crit Games）。

本作未使用该游戏的任何素材、角色、剧情设定或专有名词。
```

**为什么这样写有好处：**

| | 不声明 | 明确声明 |
| :--- | :--- | :--- |
| 学术诚信 | ❌ 未标注来源 | ✅ 标注了来源 = 借鉴 |
| 创新分 | ❌ 立论崩塌 | ✅ 可论证"机制合成是原创" |
| 评阅老师印象 | "这是抄的" | "这个学生知道边界在哪" |

### 12.6 宣传口径：强调"玩法类似"，不暗示"用了素材"

**核心原则（2026-10-26 用户决定）：**

> **对外宣传时，说"玩法类似《杀戮尖塔》"，而不是"有《杀戮尖塔》的素材"。**

#### 可以这样写 ✅

| 场景 | 措辞 |
| :--- | :--- |
| README 简介 | 「融合了《杀戮尖塔》式的卡牌构筑玩法」 |
| 宣传语 | 「如果你喜欢《杀戮尖塔》的卡组构筑，本作给出了一种东方 STG 的解法」 |
| 标签 | `卡牌构筑 / Roguelike / 弹幕射击` |
| 玩法说明 | 「每 N 秒回复 1 点能量、每 N 秒抽 1 弃 1」 |

#### 不要这样写 ❌

| 禁止 | 原因 |
| :--- | :--- |
| 标题或副标题含「杀戮尖塔」「尖塔」 | 他人商标成了你商品的身份标识 |
| 「杀戮尖塔东方版」作为主要宣传语 | 最容易被认定侵权的一类表述 |
| 「官方」「授权」「正统续作」「精神续作」 | 直接暗示背书关系 |
| 使用其 logo、字体、UI 布局、卡面风格 | 借用视觉识别，超出"玩法"范围 |
| 使用其卡名（打击 / 防御 / 猛击 / 铁甲战士等） | 专有表达 |
| 用「致敬」包装实际搬运的素材 | 声明不能把侵权变成合法 |

#### 一条界线

> **说"它像什么"是安全的；说"它就是什么"是危险的。**

- 「玩法类似《杀戮尖塔》」→ 描述**相似性**，对象是你的游戏 ✅
- 「这是《杀戮尖塔》的东方版」→ 描述**身份**，对象是别人的 IP ❌

### 12.7 一个自查法

> **问自己：这条设定如果被老师圈出来问「这是你自己想的吗」，我能不能坦然答「是」？**
>
> 能 → 用
> 只能说「我是参考某某的」→ 那它就在扣你的创新分

### 12.8 关于"魔改能存在"的辨析（留档备查）

| | 魔改虹龙洞 | 本项目 |
| :--- | :--- | :--- |
| 分发的是 | 补丁 / 差异 | 完整独立作品 |
| 玩家需要原版吗 | 需要先有正版 | 不需要 |
| 法律性质 | 修改用户已拥有的软件 | 新增一部完整作品 |

**补充：** 整合包式魔改（打包整个游戏 + 修改）是明确侵权——它重新分发了官方游戏本体。它们活着是因为没被追究，不是因为被允许。

> **风险低 ≠ 合规。合法性问题不会因为概率低就消失，它只是被搁置了。**
