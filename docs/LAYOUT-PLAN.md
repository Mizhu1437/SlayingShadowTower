# 布局重构方案（2026-11-10）

## 目标

从「中间竖版战场 + 左侧战况栏」改为**横版整体画面**：
中间是战场（正常背景），两侧是背景的虚化延伸 + 面板信息。

```
┌──────────────────────────────────────────────────────┐
│ 左侧面板              │  战场 384×448  │  右侧面板     │
│ （虚化背景延伸）       │  （正常渲染）   │ （虚化延伸）  │
└──────────────────────────────────────────────────────┘
```

## 关键约束

1. **战斗区尺寸不变**：仍是 384×448（`FIELD_W` / `FIELD_H`）。
   所有弹幕、碰撞、波次生成逻辑**一行不改**。
2. **战场内不能有任何局外信息**：分数、幕次、倒计时、残机、
   符卡、蜃銭全部移到两侧面板。
3. 两侧不是纯色，而是背景图的**同源虚化延伸**——
   取战场背景的边缘像素向两侧拉伸并模糊，视觉上连成一片。

## 实现方式

在 PixiJS 里加一个「外框容器」，包在现有 `root` 外面：

```
app.stage
└── frame (Container)
    ├── sideLeft   (Sprite，背景左边缘放大 + 模糊)
    ├── sideRight  (Sprite，背景右边缘放大 + 模糊)
    └── field (Container)   ← 现有 root，居中放置
```

DOM 面板（残机 / 符卡 / 蜃銭 / 幕次 / 倒计时）用 HTML 绝对定位在两侧，
不占用 canvas。

## 残机与符卡的东方正作式显示

不用「图标 + 数字」，改为：
- **残机**：一排小星星/菱形，每个残机一个，全部用图形绘制
- **符卡**：一排符札形，已拥有的填充、已用掉的暗淡

具体形状：残机用实心菱形，符卡用竖长圆角矩形（符札意象）。

## 牌堆快捷键

| 键 | 功能 | 展示方式 |
| :--- | :--- | :--- |
| E | 抽牌堆 | 按钮上方弹出小栏 |
| Q | 弃牌堆 | 按钮上方弹出小栏 |
| Tab | 卡组 | **正中央大 HUD，同时暂停游戏** |

三个都同时支持鼠标点击。

## 背景滚动问题的处理

素材是中景含杉林剪影（黑色三角）的 384×768 tile。
滚动时杉林反复经过，观感突兀。

处理：
- 远景速度 0（原本就如此）
- **中景速度降到 0.12**（原 0.30），让它慢到只像云影移动
- 中景加轻微模糊，弱化剪影边缘
