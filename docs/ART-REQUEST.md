# 素材生成需求书（交付给生图模型）

> **用途**：下方所有素材将被直接放入 `public/art/` 并由代码加载，文件名、尺寸、透明通道**必须严格一致**，不可自行更改。
> **风格总纲**：东方 Project 同人游戏。深色夜基调（藏青/紫），柔和发光，冷色为主、暖色点缀。无描边、无文字、无水印。
>
> **本批次不含卡牌插画** —— 卡面由项目作者后续自行设计。

---

## ⚠️ 先读：这是两类完全不同的素材

本作需要两种画法，**不能混用、不能只做一种**：

| | **立绘 / 插画** | **战斗像素绘** |
| :--- | :--- | :--- |
| 用在哪 | 机体选择界面、敌人图鉴 | 战斗画面里飞的那个小东西 |
| 画法 | 精细插画，可含渐变、光效 | **像素画（pixel art）**，硬边、无渐变、锯齿感 |
| 尺寸 | 大（600×900 等） | 小（32×32 ～ 96×96） |
| 缩放 | 1:1 显示 | 会被放大 1.5–2 倍显示，**必须是整数倍缩放不糊** |
| 背景 | 透明 | 透明 |
| 数量 | 自机 1 + 敌人若干 | 自机 1 + 敌人 7 |

**为什么战斗里必须用像素绘**：战斗画面本身是低分辨率风格（战场逻辑尺寸只有 384×448），
一张精细插画缩到 32px 会变成一团模糊的色块，完全没有辨识度。
像素绘在同样尺寸下每个像素都是有效信息。

**像素绘的硬性要求**：
- 必须**硬边缘**，不要抗锯齿、不要柔和阴影
- 颜色数控制在 **16 色以内**（含透明）
- 输出时请**整数倍放大**到你标注的尺寸（例如 16×16 画好后放大到 64×64），
  放大必须用**最近邻（nearest neighbor）**，不要用平滑插值
- 轮廓要有 1px 深色描边，方便在深色背景上看清

---

## 零、三条硬性技术约束（违反则无法使用）

| 约束 | 说明 |
| :--- | :--- |
| **1. 尺寸精确** | 每张图必须按表中标注的像素尺寸输出，不可缩放、不可留白边 |
| **2. 需要透明的地方必须真透明** | 标注 RGBA 的素材，背景必须是 alpha=0 的透明，不是黑底、不是白底 |
| **3. 背景图必须纵向无缝** | 标注「无缝」的素材会被上下循环拼接滚动，**第一行像素必须与最后一行像素接近**，否则滚动时会出现横向接缝 |

## 一、关卡背景（4 幕 × 2 层 = 8 张）

### 技术规格

| 项 | 值 |
| :--- | :--- |
| 尺寸 | **384 × 768**（竖版，宽=384，高=768） |
| 格式 | `_far` 层：PNG **不透明**（它是天空底）；`_near` 层：PNG **RGBA**（需要透明） |
| 平铺方式 | **纵向无缝循环**，即「第一行 ≈ 最后一行」 |
| 滚动速度 | far 层几乎不动、near 层滚动较快 |

### ⚠️ 关键构图约束（很容易踩）

1. **画面主体必须位于垂直方向的中间区域**（大约 25%–75% 高度）。
   上下一共 320px 是留给循环拼接的，那里只能有渐变/雾/星空，**不能出现山、塔、树枝等具体物体**，否则拼起来会出现"一个物体被切成两半"。
2. **必须左右横向均匀**。画面左右两侧各 24px 会被单独裁下来拉伸成"战场两侧的延伸带"，若那里有不对称的物体，拉伸后会变成难看的条纹。
3. **不要画任何横向的直线/横条**（如地平线、栏杆），滚动时会明显看出接缝。

### 四幕的场景设定

| 幕 | 场景 | 色调 |
| :--- | :--- | :--- |
| 第一幕 | 妖怪之山 · 流言 —— 山间夜空，远处有塔的轮廓 | 深紫夜蓝 |
| 第二幕 | 塔内 · 影像 —— 塔的一层，虚影与幻象 | 蓝紫偏冷 |
| 第三幕 | 塔内 · 伪真 —— 更深一层，几何符文浮现 | 紫灰 |
| 第四幕 | 塔顶 · 剥落 —— 接近真相，天空裂开透光 | 橙紫黎明感 |

| 文件名 | 层 | 内容要求 |

## 四、自机像素绘（1 张）

### 技术规格

| 项 | 值 |
| :--- | :--- |
| 格式 | PNG，**RGBA 透明背景** |
| 画法 | **像素画**：硬边、无渐变、每个像素都是实色 |
| 放大方式 | 先在 **1/4 或 1/2 的小尺寸**画好，再用**最近邻（nearest）**整数倍放大到标注尺寸 |
| 描边 | 轮廓 1px 深色描边（在深色背景上能看清） |
| 颜色数 | 每张 ≤16 色（含透明） |

> **为什么强调最近邻**：用平滑插值放大，像素点会被抹成模糊的色块，
> 在低分辨率战场里会糊成一团，辨识度全无。

### 自机（1 张）

| 文件名 | 尺寸 | 内容 |
| :--- | :--- | :--- |
| `pixel_player.png` | **48 × 48** | 藤原妹红的自机形象。**俯视/正上视角**（弹幕游戏是俯视视角，不是正面立绘）。银白发 + 红背带裤，脚下有火焰尾迹。要求在最小时（缩到 32px）也能一眼认出「银白 + 红」这个人 |

**关键**：自机在游戏里会被缩到 32–48px 显示，所以**轮廓和配色比细节重要**。不要画脸、不要画五官（看不清），用大色块表现造型。

#### 朝向硬性要求：必须是**背面**

自机在战场上**朝上飞**，玩家从头后方俯视，因此只能看到**背面**：

| 能看到的 | 不能出现的 |
| :--- | :--- |
| 后脑与整片银白长发 | **脸**（眼睛、鼻子、嘴） |
| 白发覆盖肩背 | **正面衣襟 / 领口 V 字** |
| 背带裤的**两条背带在背后** | 胸口、锁骨等正面皮肤 |
| 下垂的双手、靴底火焰 | — |

> 生成结果若给了正面（头部有脸、胸口有 V 领），**镜像救不了** ——
> 镜像只改左右，不改朝向。必须重新生成。
>
> 提示词里直接写：`seen from behind, back of head, no face, facing away from viewer,
> top-down view of the back, hair covering the shoulders`。

### 敌人不在此列

敌人（杂兵、精英、BOSS）**不使用像素图**，由代码用几何图形直接绘制
（圆形 + 三角 + 发光层）。这样能保证：

- 体型与碰撞半径严格对应，不会出现「图大判定小」
- 颜色随状态变化（受击闪白、虚弱变色）无需准备额外素材
- 不占素材预算

## 六、敌人立绘（2 张，战斗前对话用）

### 用途

每幕关底 BOSS 战之前，会弹出一段**对话画面**：左侧或右侧是立绘，下方是台词框。
这是东方正作的固定演出形式，也是本作交代剧情的主要场合。

### 与战斗表现的关系

敌人立绘是**插画**，用在战斗前的对话画面。
战场上敌人的样子由代码用几何图形绘制（见第四节「敌人不在此列」），不需要像素图。

因此敌人只需要**一层**素材（立绘），不必像自机那样准备「立绘 + 像素绘」两套。
但立绘的配色会成为战场上几何图形的取色依据，所以请让主色调明确。

### 技术规格

| 项 | 值 |
| :--- | :--- |
| 尺寸 | **700 × 1000**（竖版） |
| 格式 | PNG，**RGBA 透明背景** |
| 构图 | **半身像**（腰部以上），人物略偏向一侧，另一侧留给台词框 |
| 视线 | **见下方「朝向硬性要求」** |

#### 朝向硬性要求（生成时必须遵守）

对话画面的站位是固定的：**自机在左、敌人在右**。
因此朝向不能含糊，否则两人会背对背说话。

| 素材 | 站位 | 必须朝 | 判断标准 |
| :--- | :--- | :--- | :--- |
| `chara_mokou.png` | 画面**左**侧 | **朝右** | 鼻尖、下巴、视线指向画面右侧 |
| `enemy_chiyi.png` | 画面**右**侧 | **朝左** | 鼻尖、下巴、视线指向画面左侧 |
| `enemy_beizi.png` | 画面**右**侧 | **朝左** | 同上 |

> **注意：朝内，不是朝外。** 早期版本写成「看向画面外侧」，
> 生成结果两人都朝外，对话时互相背对，已被镜像修正。
>
> 代码侧也有兜底：`tools/process_generated_art.py` 的 `PORTRAITS`
> 第 4 个字段是镜像开关，源图朝反了就用它扳回来，不必重新生成。

## 十、验收自检（生成后请逐条确认）

**背景类**
- [ ] 所有背景图**第一行 ≈ 最后一行**（可上下拼接无明显接缝）
- [ ] 所有背景图的主体不在最上/最下 160px 内
- [ ] 所有背景图左右两侧 24px 内**没有不对称物体**

**自机像素绘**
- [ ] 是**像素画**，不是插画缩小图
- [ ] 颜色数 ≤64（含透明）
- [ ] 是**整数倍最近邻放大**的，没有模糊边缘
- [ ] 缩到 32px 时仍能认出「银白 + 红」
- [ ] **是背面**：没有脸，没有正面衣襟

**立绘类（3 张）**
- [ ] 3 张立绘都是**透明背景**
- [ ] 人物不要画出画面外（半身像，腰部以上完整）
- [ ] **朝向正确**：自机朝右、两张敌人朝左（见第二节「朝向硬性要求」）

**通用**
- [ ] 标注 RGBA 的图，透明区域是真透明（不是黑底）
- [ ] 所有文件名与上表**完全一致**（区分大小写，无空格）
- [ ] 所有尺寸与上表**完全一致**
- [ ] 没有任何图片包含文字
- [ ] `act_banner_*` 中央 240px 是空的

### 验收要点

生成后对照这四条，任何一条不满足就重做：

| 检查 | 不通过的表现 |
| :--- | :--- |
| 是背面 | 看得到眼睛、鼻子、嘴 |
| 没有正面衣襟 | 胸口有 V 领、锁骨、正面扣子 |
| 背带在背后 | 背带出现在肚子前面 |
| 是像素画 | 边缘有半透明过渡色（抗锯齿） |

> **镜像不能解决朝向问题。** 镜像只翻转左右，正面还是正面。
