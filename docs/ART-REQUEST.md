# 素材生成需求书（交付给生图模型）

> **用途**：下方所有素材将被直接放入 `public/art/` 并由代码加载，文件名、尺寸、透明通道**必须严格一致**，不可自行更改。
> **风格总纲**：东方 Project 同人游戏。深色夜基调（藏青/紫），柔和发光，冷色为主、暖色点缀。无描边、无文字、无水印。
>
> **本批次不含卡牌插画** —— 卡面由项目作者后续自行设计。

## 零、三条硬性技术约束（违反则无法使用）

| 约束 | 说明 |
| :--- | :--- |
| **1. 尺寸精确** | 每张图必须按表中标注的像素尺寸输出，不可缩放、不可留白边 |
| **2. 需要透明的地方必须真透明** | 标注 RGBA 的素材，背景必须是 alpha=0 的透明，不是黑底、不是白底 |
| **3. 背景图必须纵向无缝** | 标注「无缝」的素材会被上下循环拼接滚动，**第一行像素必须与最后一行像素接近**，否则滚动时会出现横向接缝 |

## 一、关卡背景（4 幕 × 2 层 = 8 张）

### 技术规格

| 项 | 值 |
| :--- | :--- |
| 尺寸 | **384 × 768**（竖版，宽=384，高=768） |
| 格式 | `_far` 层：PNG **不透明**（它是天空底）；`_near` 层：PNG **RGBA**（需要透明） |
| 平铺方式 | **纵向无缝循环**，即「第一行 ≈ 最后一行」 |
| 滚动速度 | far 层几乎不动、near 层滚动较快 |

### ⚠️ 关键构图约束（很容易踩）

1. **画面主体必须位于垂直方向的中间区域**（大约 25%–75% 高度）。
   上下一共 320px 是留给循环拼接的，那里只能有渐变/雾/星空，**不能出现山、塔、树枝等具体物体**，否则拼起来会出现"一个物体被切成两半"。
2. **必须左右横向均匀**。画面左右两侧各 24px 会被单独裁下来拉伸成"战场两侧的延伸带"，若那里有不对称的物体，拉伸后会变成难看的条纹。
3. **不要画任何横向的直线/横条**（如地平线、栏杆），滚动时会明显看出接缝。

### 四幕的场景设定

| 幕 | 场景 | 色调 |
| :--- | :--- | :--- |
| 第一幕 | 妖怪之山 · 流言 —— 山间夜空，远处有塔的轮廓 | 深紫夜蓝 |
| 第二幕 | 塔内 · 影像 —— 塔的一层，虚影与幻象 | 蓝紫偏冷 |
| 第三幕 | 塔内 · 伪真 —— 更深一层，几何符文浮现 | 紫灰 |
| 第四幕 | 塔顶 · 剥落 —— 接近真相，天空裂开透光 | 橙紫黎明感 |

### 逐张清单

| 文件名 | 层 | 内容要求 |
| :--- | :--- | :--- |
| `act1_far.png` | 远景 | 深紫夜空 + 稀疏星点 + 极淡云气。整体很暗（亮度约 10%），几乎只是氛围底 |
| `act1_near.png` | 近景 | **几乎全透明**，只在中间区域有极淡的雾霭/光尘纹理（约 5% 不透明度），主要靠 alpha 表现 |
| `act2_far.png` | 远景 | 塔内：深蓝紫的室内空气感，隐约的柱状剪影在**垂直中部**，上下渐变到纯色 |
| `act2_near.png` | 近景 | 近乎全透明，中间区域有漂浮的微光粒子 |
| `act3_far.png` | 远景 | 塔内更深一层：偏紫灰，抽象的几何轮廓（菱形/圆形符文），依然集中在中部 |
| `act3_near.png` | 近景 | 近乎全透明 + 淡紫色雾 |
| `act4_far.png` | 远景 | 塔顶/天空：偏暖的橙紫色黎明感，云层横向铺开但**不要画成横条纹**，用柔和的斑块表现 |
| `act4_near.png` | 近景 | 近乎全透明 + 暖色光尘 |

> **near 层说明**：这一层几乎看不见是设计如此（渲染时叠加在 far 之上），它的作用是让画面有细微的空气流动感。**宁可太淡，不要画太重**。现有素材的 near 层平均亮度只有 1/255，你产出的也可以同样淡。

## 二、遮罩层（4 张）

| 项 | 值 |
| :--- | :--- |
| 文件名 | `act1_overlay.png` ～ `act4_overlay.png` |
| 尺寸 | **384 × 448** |
| 格式 | PNG，**RGBA** |

**作用**：叠在背景之上，压暗画面、提升弹幕可读性。

**要求**：
- 整体是一层**半透明的深色**（alpha 约 40%–70%），从上到下有轻微渐变
- 顶部略深（压暗天空），底部略浅
- **不要**有任何图案、纹理、边框

## 四、机体立绘（1 张，当前项目最缺的素材）

| :--- | :--- |
| 文件名 | `chara_mokou.png` |

| 格式 | PNG，**RGBA 透明背景**（人物之外必须透明） |

## 附：一键验收

把素材按上面的目录结构放好后，运行：

```bash
python tools/check_art.py <素材目录>
```

脚本会逐项检查尺寸、透明通道、纵向无缝、主体位置，并列出所有不合规条目。全部通过即可直接放进 `public/art/`。
