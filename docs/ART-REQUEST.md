# 素材生成需求书（交付给生图模型）

> **用途**：下方所有素材将被直接放入 `public/art/` 并由代码加载，文件名、尺寸、透明通道**必须严格一致**，不可自行更改。
> **风格总纲**：东方 Project 同人游戏。深色夜基调（藏青/紫），柔和发光，冷色为主、暖色点缀。无描边、无文字、无水印。
>
> **本批次不含卡牌插画** —— 卡面由项目作者后续自行设计。

---

## ⚠️ 先读：这是两类完全不同的素材

本作需要两种画法，**不能混用、不能只做一种**：

| | **立绘 / 插画** | **战斗像素绘** |
| :--- | :--- | :--- |
| 用在哪 | 机体选择界面、敌人图鉴 | 战斗画面里飞的那个小东西 |
| 画法 | 精细插画，可含渐变、光效 | **像素画（pixel art）**，硬边、无渐变、锯齿感 |
| 尺寸 | 大（600×900 等） | 小（32×32 ～ 96×96） |
| 缩放 | 1:1 显示 | 会被放大 1.5–2 倍显示，**必须是整数倍缩放不糊** |
| 背景 | 透明 | 透明 |
| 数量 | 自机 1 + 敌人若干 | 自机 1 + 敌人 7 |

**为什么战斗里必须用像素绘**：战斗画面本身是低分辨率风格（战场逻辑尺寸只有 384×448），
一张精细插画缩到 32px 会变成一团模糊的色块，完全没有辨识度。
像素绘在同样尺寸下每个像素都是有效信息。

**像素绘的硬性要求**：
- 必须**硬边缘**，不要抗锯齿、不要柔和阴影
- 颜色数控制在 **16 色以内**（含透明）
- 输出时请**整数倍放大**到你标注的尺寸（例如 16×16 画好后放大到 64×64），
  放大必须用**最近邻（nearest neighbor）**，不要用平滑插值
- 轮廓要有 1px 深色描边，方便在深色背景上看清

---

## 零、三条硬性技术约束（违反则无法使用）

| 约束 | 说明 |
| :--- | :--- |
| **1. 尺寸精确** | 每张图必须按表中标注的像素尺寸输出，不可缩放、不可留白边 |
| **2. 需要透明的地方必须真透明** | 标注 RGBA 的素材，背景必须是 alpha=0 的透明，不是黑底、不是白底 |
| **3. 背景图必须纵向无缝** | 标注「无缝」的素材会被上下循环拼接滚动，**第一行像素必须与最后一行像素接近**，否则滚动时会出现横向接缝 |

## 一、关卡背景（4 幕 × 2 层 = 8 张）

### 技术规格

| 项 | 值 |
| :--- | :--- |
| 尺寸 | **384 × 768**（竖版，宽=384，高=768） |
| 格式 | `_far` 层：PNG **不透明**（它是天空底）；`_near` 层：PNG **RGBA**（需要透明） |
| 平铺方式 | **纵向无缝循环**，即「第一行 ≈ 最后一行」 |
| 滚动速度 | far 层几乎不动、near 层滚动较快 |

### ⚠️ 关键构图约束（很容易踩）

1. **画面主体必须位于垂直方向的中间区域**（大约 25%–75% 高度）。
   上下一共 320px 是留给循环拼接的，那里只能有渐变/雾/星空，**不能出现山、塔、树枝等具体物体**，否则拼起来会出现"一个物体被切成两半"。
2. **必须左右横向均匀**。画面左右两侧各 24px 会被单独裁下来拉伸成"战场两侧的延伸带"，若那里有不对称的物体，拉伸后会变成难看的条纹。
3. **不要画任何横向的直线/横条**（如地平线、栏杆），滚动时会明显看出接缝。

### 四幕的场景设定

| 幕 | 场景 | 色调 |
| :--- | :--- | :--- |
| 第一幕 | 妖怪之山 · 流言 —— 山间夜空，远处有塔的轮廓 | 深紫夜蓝 |
| 第二幕 | 塔内 · 影像 —— 塔的一层，虚影与幻象 | 蓝紫偏冷 |
| 第三幕 | 塔内 · 伪真 —— 更深一层，几何符文浮现 | 紫灰 |
| 第四幕 | 塔顶 · 剥落 —— 接近真相，天空裂开透光 | 橙紫黎明感 |

### 逐张清单

| 文件名 | 层 | 内容要求 |
| :--- | :--- | :--- |
| `act1_far.png` | 远景 | 深紫夜空 + 稀疏星点 + 极淡云气。整体很暗（亮度约 10%），几乎只是氛围底 |
| `act1_near.png` | 近景 | **几乎全透明**，只在中间区域有极淡的雾霭/光尘纹理（约 5% 不透明度），主要靠 alpha 表现 |
| `act2_far.png` | 远景 | 塔内：深蓝紫的室内空气感，隐约的柱状剪影在**垂直中部**，上下渐变到纯色 |
| `act2_near.png` | 近景 | 近乎全透明，中间区域有漂浮的微光粒子 |
| `act3_far.png` | 远景 | 塔内更深一层：偏紫灰，抽象的几何轮廓（菱形/圆形符文），依然集中在中部 |
| `act3_near.png` | 近景 | 近乎全透明 + 淡紫色雾 |
| `act4_far.png` | 远景 | 塔顶/天空：偏暖的橙紫色黎明感，云层横向铺开但**不要画成横条纹**，用柔和的斑块表现 |
| `act4_near.png` | 近景 | 近乎全透明 + 暖色光尘 |

> **near 层说明**：这一层几乎看不见是设计如此（渲染时叠加在 far 之上），它的作用是让画面有细微的空气流动感。**宁可太淡，不要画太重**。现有素材的 near 层平均亮度只有 1/255，你产出的也可以同样淡。

## 二、遮罩层（4 张）

| 项 | 值 |
| :--- | :--- |
| 文件名 | `act1_overlay.png` ～ `act4_overlay.png` |
| 尺寸 | **384 × 448** |
| 格式 | PNG，**RGBA** |

**作用**：叠在背景之上，压暗画面、提升弹幕可读性。

**要求**：
- 整体是一层**半透明的深色**（alpha 约 40%–70%），从上到下有轻微渐变
- 顶部略深（压暗天空），底部略浅
- **不要**有任何图案、纹理、边框

## 四、战斗像素绘（8 张：自机 1 + 敌人 7）

### 技术规格

| 项 | 值 |
| :--- | :--- |
| 格式 | PNG，**RGBA 透明背景** |
| 画法 | **像素画**：硬边、无渐变、每个像素都是实色 |
| 放大方式 | 先在 **1/4 或 1/2 的小尺寸**画好，再用**最近邻（nearest）**整数倍放大到标注尺寸 |
| 描边 | 轮廓 1px 深色描边（在深色背景上能看清） |
| 颜色数 | 每张 ≤16 色（含透明） |

> **为什么强调最近邻**：用平滑插值放大，像素点会被抹成模糊的色块，
> 在低分辨率战场里会糊成一团，辨识度全无。

### 自机（1 张）

| 文件名 | 尺寸 | 内容 |
| :--- | :--- | :--- |
| `pixel_player.png` | **48 × 48** | 藤原妹红的自机形象。**俯视/正上视角**（弹幕游戏是俯视视角，不是正面立绘）。银白发 + 红背带裤，脚下有火焰尾迹。要求在最小时（缩到 32px）也能一眼认出「银白 + 红」这个人 |

**关键**：自机在游戏里会被缩到 32–48px 显示，所以**轮廓和配色比细节重要**。不要画脸、不要画五官（看不清），用大色块表现造型。

### 敌人（7 张）

| 文件名 | 尺寸 | 类型 | 内容 |
| :--- | :--- | :--- | :--- |
| `pixel_grunt.png` | **32 × 32** | 杂兵（血量 12） | 最小的杂兵。紫色小妖精，单眼，轮廓简单，容易被忽略 |
| `pixel_fan.png` | **40 × 40** | 扇形弹敌（血量 20） | 蓝紫色妖精，双手张开呈扇形，比 grunt 大一圈 |
| `pixel_ring.png` | **48 × 48** | 环形弹敌（血量 30） | 青紫色带环状装饰的妖精，轮廓呈圆形 |
| `pixel_elite_spiral.png` | **56 × 56** | 精英·螺旋（血量 80） | 深紫色精英，身上有螺旋纹路，比普通杂兵明显更「重」 |
| `pixel_elite_burst.png` | **60 × 60** | 精英·爆发（血量 120） | 暗红色精英，体型偏宽，看起来有攻击性 |
| `pixel_midboss.png` | **80 × 80** | 道中 BOSS（血量 600） | 中型 BOSS。人形或妖异的轮廓，比精英再多一圈装饰/光环，有压迫感 |
| `pixel_boss.png` | **96 × 96** | 关底 BOSS（血量 1800） | 本幕最终 BOSS。**最大、最华丽**，周围可带一圈装饰性光环。要一眼看出「这是老大」 |

**尺寸与游戏内半径的对应**（供参考，不用改）：
`grunt` 半径 11px、`fan` 13px、`ring` 17px、`elite_spiral` 20px、`elite_burst` 22px、`midboss` 30px、`boss` 38px。
所以上表的贴图尺寸是按「半径 × 约 2.5」给的，留出了视觉余量。

### 敌人之间的区分度（重要）

7 种敌人在战场上可能同时出现，玩家需要在**一瞬间**分清哪个是杂兵、哪个是精英、哪个是 BOSS。
请用**体型 + 主色调 + 轮廓复杂度**三重区分：

| | 体型 | 主色 | 轮廓 |
| :--- | :--- | :--- | :--- |
| 杂兵 | 小 | 紫 | 极简，一眼扫过 |
| 精英 | 中 | 深紫 / 暗红 | 有额外装饰（角、翼、纹） |
| BOSS | 大 | 金 / 赤 | 最复杂，带光环 |

## 六、敌人立绘（2 张，战斗前对话用）

### 用途

每幕关底 BOSS 战之前，会弹出一段**对话画面**：左侧或右侧是立绘，下方是台词框。
这是东方正作的固定演出形式，也是本作交代剧情的主要场合。

### 与战斗像素绘的关系

| | 敌人立绘 | 敌人像素绘 |
| :--- | :--- | :--- |
| 用在哪 | 战斗前的对话画面 | 战场里飞的那个 |
| 画法 | 精细插画 | 像素画 |
| 尺寸 | 竖版大图 | 32–96px |
| 数量 | 2（已定稿的 BOSS） | 7（各类杂兵与 BOSS） |

**两者是同一角色的两种画法**，配色、发型、服装必须一致，玩家才能认出「对话里这个人」就是「刚才打的那个」。

### 技术规格

| 项 | 值 |
| :--- | :--- |
| 尺寸 | **700 × 1000**（竖版） |
| 格式 | PNG，**RGBA 透明背景** |
| 构图 | **半身像**（腰部以上），人物略偏向一侧，另一侧留给台词框 |
| 视线 | 看向画面外侧（与自机对话的方向感） |

## 十、验收自检（生成后请逐条确认）

**背景类**
- [ ] 所有背景图**第一行 ≈ 最后一行**（可上下拼接无明显接缝）
- [ ] 所有背景图的主体不在最上/最下 160px 内
- [ ] 所有背景图左右两侧 24px 内**没有不对称物体**

**像素绘类**
- [ ] 8 张像素绘**都是像素画**，不是插画缩小图
- [ ] 每张像素绘颜色数 ≤64（含透明）
- [ ] 像素绘是**整数倍最近邻放大**的，没有模糊边缘
- [ ] 自机缩到 32px 时仍能认出「银白 + 红」

**立绘类**
- [ ] 机体立绘与 2 张敌人立绘都是**透明背景**
- [ ] 立绘人物不要画出画面外（半身像，腰部以上完整）

**通用**
- [ ] 标注 RGBA 的图，透明区域是真透明（不是黑底）
- [ ] 所有文件名与上表**完全一致**（区分大小写，无空格）
- [ ] 所有尺寸与上表**完全一致**
- [ ] 没有任何图片包含文字
- [ ] `act_banner_*` 中央 240px 是空的

## 附：一键验收

把素材按上面的目录结构放好后，运行：

```bash
python tools/check_art.py <素材目录>
```

脚本会逐项检查尺寸、透明通道、纵向无缝、主体位置，并列出所有不合规条目。全部通过即可直接放进 `public/art/`。
